# Ideas

This folder collects early or unstructured thoughts before they evolve into formal designs.

Use it for:
- New workflow concepts  
- Potential features or automation use cases  
- Notes from brainstorming sessions  
- “What if…” scenarios not yet researched or planned  

Keep entries short and informal — bullet lists, sketches, or links are fine.

File naming convention:
`YYYYMMDD-short-idea.md`  
(example: `20251105-ai-tagging-idea.md`)
