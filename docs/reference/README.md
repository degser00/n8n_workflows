# Reference

This folder provides static or reusable information that supports workflow development and operations.

Use it for:
- API schemas, endpoints, and field mappings  
- Configuration variable lists and environment templates  
- Credential inventory (non-sensitive descriptions only)  
- Data model definitions (e.g., PostgreSQL schema overview)  
- Naming conventions, tagging rules, or glossary entries  
- Links to authoritative external documentation  

Documents here should be **stable and version-agnostic**, unlike design or ops docs which may evolve with implementation.

File naming convention:
`REF-####-topic-name.md`  
(example: `REF-1234-n8n-env-vars.md`, `REF-2345-github-api-schema.md`)
