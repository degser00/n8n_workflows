# Research

This folder contains exploratory findings, benchmarks, and feasibility studies.

Use it to record:
- Tool or API comparisons  
- Integration tests or proof-of-concept results  
- Performance or scalability notes  
- Security or compliance considerations  
- Summaries of external resources  

When an idea matures, summarize findings here and reference them from a design doc.

File naming convention:
`RES-####-topic.md`  
(example: `RES-0001-n8n-github-api-research.md`)
